# Brick-Out

Classic brick breaker written in plain JavaScript and HTML5 Canvas, no libraries.

- 98 levels, ordered from easy to hard
- Power-ups (lasers, fire ball, slow, multi-ball), combo system, local high scores
- Works with mouse and with touch screens (drag to move, tap to start or shoot)

Run: open `index.html` in a browser (or host the folder on GitHub Pages / itch.io).
